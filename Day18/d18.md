#### Passing functions as props
- A parent can pass a function to a child, and the child can call that function to communicate back to the parent.
- This is how components share actions without diretly modifying each other's state.

**Parent owns the state**
```tsx
function App(){
    const [count, setCount] = useState(0);
    return(
        <div>
        <p>Count: {count}</p>
        <CounterButton onIncrease={() =>{
            setCount(prev => prev+1);
        }} />
        </div>
    );
}
```
- App owns the state `const [count, setCount] = useState(0);`.So, App is responsible for count.
- App passes a function to CounterButton (child component/function).
- onIncrease is a prop in CounterButton and App sends a function `() =>{setCount(prev => prev+1);` to CounterButton.

```tsx
type CounterButtonProp = {
    onIncrease: () => void;
};

function CounterButton(onIncrease: CounterButtonProp){
    return(
        <button onClick={onIncrease}>Increase</button>
    );
}
```
- This is parent sends function as props in child.
- Now we reverse that process:
- Child function pass an argument as a function in parent class.
- So child send information to the parent.


**Passing arguments through the function**
```tsx
type UserButtonProps = {
    onSelect: (name: string) => void;
}

function Child(onSelect: UserButtonProps){
    return(
        <button onClick={() => {
            onSelect("Tharun");
        }}>Select User</button>
    );
}

function Parent(){
    function handleSelect(name:string){
        console.log(Selected Name: {name});
    }
    return(
        <div>
            <Child onSelect={handleSelect} />
        </div>
    );
}
```
