#### API fetching with async/await + reusable fetch function

- Previous lesson we fetched users directly inside useEffect.
- But now we'll improve the structure by seperating the API request logic from the react component.

**Previous approach**
```tsx
useEffect(() => {
    async function fetchUsers(){
        const response = await fetch("https://jsonplaceholder.typicode.com/users");
        const data: User[] = await response.json();
        setUser(data);
    }

    fetchUsers();
}, []);
```
- It works but imagine you need to fetch users from three different components.
- You don't want to copy the same fetch code everywhere.

**Create an API function**
```tsx
async function getUsers(): Promise<User[]>{
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    if(!response.ok){
        throw new Error("Failed to Fetch users");
    }
    const data: User[] = await response.json();
    return data;
}
```
- An async function always returns Promise and that promise type is an array.

**Use API function**
```tsx
useEffect(() => {
    async function loadUsers(){
        try{
            const data = await getUsers();
```
