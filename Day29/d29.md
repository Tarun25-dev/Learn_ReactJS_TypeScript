#### Creating a reusable custom hook

- We'll learn how to extract reusable logic into your own hook.
- A custom hook is simply a function whose name starts with `use` and which can use other react hooks.
**The Problem**
- Suppose you repeatedly need this Logic:
```tsx
const [count, setCount] = useState(0);
function increase(){
    setCount(prev => prev + 1);
}
function decrease(){
    setCount(prev => prev + 1);
}
```
- Instead of repreating this code in multiple components, we can create:
```tsx
function useCount(){
    // reusable logic
}
```
**Create custom hook**
```tsx
function useCounter(){
    const  [count, setCount] = useState(0);
    function increase(){
        setCount(prev => prev + 1);
    }
    function decrease(){
        setCount(prev => prev + 1);
    }
    function reset(){
        setCount(0);
    }
    return {
        count,
        increase,
        decrease,
        reset,
    };
}
```
- React recognizes it as a hook beacuse of useCounter.
**Use it inside a component**
```tsx
function App(){
    const {count,increase,decrease,reset} = useCounter();
    return(
        <div>
            <p>Count: {count}</p>
            <button onClick={increase}>Increase</button>
            <button onClick={decrease}>Decrease</button>
            <button onClick={reset}>Reset</button>
        </div>
    );
}
```
- This componet doesn't need to know how the counter works internally.
