#### Error Boundaries:
- Error Boundraies are a way to prevent one broken component from crashing the entire React UI.
**The Problem:**
- Imagine:
```text
App
|_____Navbar
|_____Products
|_____Profile
```
- Incase in any crashes by Profile component, Without an error boundary, a rendering error can cause the UI to fail.
- An Error Boundary lets us show a fallback instead like Profile raised some error and Error boundary actives and keeps UI interactice by using fallback, "someThing went wrong".

**Error Boundary is a class component**
- Unlike most modern React components you have been learning the traditional Error Boundary API uses a class component.
```tsx
import {Component, ReactNode} from "react";
```
- We will create a type:
```tsx
type Props = {
    children: ReactNode;
};

type State = {
    hasError: boolean;
};
```

**Create the Error Boundary**
```tsx
class ErrorBoundary extends Components<Props, State>{
    state: State = {
        hasError: false,
    };

    static getDerivedStateFromError(): State{
        return {
            hasError: true,
        };
    }
    render(){
        if(this.state.hasError){
            return (<div><h1>Something went Wrong!</h1><p>This section could not be displayed.</p></div>);
        }
        return this.props.children;
    }
}
```
- import {Component} = Component is the base class provided by React. You App class extends it to become a React class component.
- why inside curly braces {Component} beacuse Component is a named export, so you use curly braces.
- ErrorBoundary extends Component = Component gives your class(ErrorBoundary) react component behaviour.
- render() is a method from Component class and used to defines what component displays.
- Component accepts two generic types Props and State `Component<Props, Static>`

- static keyword = main use is when the method belongs to the class itself, not to individual objects.
- use Static when the method logically belongs to the class and doesn't need a particular objects data.

- ReactNode is a typescript type provided by React. You import it when you want to specify that a value can be anything React can Render.
- Here children value can be anthing react will render. 
- We will learn in detail upcoming topics.

- **Important:** static getDerivedStateFromError() method, When a child throws during rendering React calls this method and updates the state.
- Then the fallback UI is rendered.

**Use it around a component**
- Create component that intentionally throws an error to test:
```tsx
function BrokenComponent(){
    throw new Error("Something Went Wrong");

    return <div>This won't render</div>;
}
```
- Then 
```tsx
function App(){
    return(
        <>
        <ErrorBoundary>
        <BrokenComponent />
        </ErrorBoundary>
        </>
    );
}
```
