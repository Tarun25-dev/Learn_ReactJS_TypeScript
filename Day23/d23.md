#### useRef - Referencing DOM elements

- useRef is commonly used when you need to access a DOM element directly or keep a value between renders without causing a re-render.
- Suppose we have an input and want to focus it when we click a button:
```tsx
import {useRef} from "react";

function App(){
    const inputRef = useRef<HTMLInputElement>(null);
    
    function handleFocus(){
        inputRef.current?.focus();
    }
    return(
        <div>
            <input ref={inputRef} />
            <button onClick={handleFocus}>Focus Input</button>
        </div>
    );

}

```
- focus() is a DOM method that puts the keyboard cursor/focus on an element.
- useRef is created during the first render and react remembers the same ref object across future renders.
- But using a normal varible is recreated when the component function runs again.
- Think of it like a labeled box:   `const inputRef = useRef<HTMLInputElement>(null);`
- Then you attach that box to an element: `<input ref={inputRef} />`
- Now access that element:   `inputRef.current?.focus();`
- inputRef.current value is null when use doesn't click and when does it has that input element and add that focus method on input.

**useState VS useRef**
- useState: If something the value should update the screen.
- useRef: If you need to remember a value without causing render or access a DOM element.

**useRef can remember a value**
```tsx
const renderCount = useRef(0);
renderCount.current +=1
```
