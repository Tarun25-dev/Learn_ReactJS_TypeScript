**What is React?**

React is a javascript library for building user interfaces, especially web applications.
- It was created by Facebook(now Meta).
- The key idea is: Build your UI using small, reusable components.
- Instead of writing one huge HTML/Javascript file, React lets you resuable components.
- Like Create one React component and Reuse it.

**Why was React created?**
- Before React, websites were often built using:
- HTML, CSS, Javascript -> DOM manipulation.
- For simple wensites this was fine.
- But applications like facebook became very large and highly interactive.
- If something changes, the UI needs to update.
- Managing all those DOM changes manually becomes complicated.
- React was designed to make this easier.
- React doesn't normally rebulid the entire real DOM page. It determines what needs to change and applies the necessary DOM updates.

**React History**
- 2011: **Jordan Walke** (software engineering at facebook) created the early version of React at Facebook. 
- 2012: Facebook started using React internally.
- 2013: Facebook publicly open-sourced React at JSConfUS.
- Today: React is maintained by Meta and the open-source community.
