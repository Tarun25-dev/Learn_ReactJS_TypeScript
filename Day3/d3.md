#### Props(Properties)

**Props - Passing Data between components**
- Data passed from a parent component to a child component.

**Understand the Flow:**
- Suppose App has a user's name:

```tsx
function App() {
    const name = "tharun";

    return <User name={name} />;
}
```
- Here App component passes name to the User component.
- The User component receives that data through Props.

**Receiving props with Typescript**
- create two components like App.tsx and User.tsx
- User.tsx
```tsx
type UserProps = {name: string;};

function User({name}: UserProps){
    return <h2>Hello {name}</h2>
}

export default User;
```

**Passing the prop**

```tsx
import User from "./User.tsx";

function App() {
    return (
        <div>
        <h1>My App</h1>
        <User name="Tharun" />
        </div>
    );
}
```

**Passing Multiple Props**

```tsx
type UserProps = {
    name: string;
    age: number;
    city: string;
};

function User({name, age, city}: UserProps){
    return (
        <div>
        <h2>{name}</h2>
        <p>Age: {age}</p>
        <p>City: {city}</p>
        </div>
    );
}

export default User;
```
```tsx
import User from "./User.tsx";

function App(){
    return(
        <>
        <User name ="tharun" age = {23} city = "Nandyal"/>
        </>
    );
}
```
- JSX gives you two main ways to provide an attribute value:
- [1]. <User age="23" /> // This is a string.
- [2]. <User age={23} /> // we can use {} for numbers, booleans, objects, arrays, expressions,etc.

**Why typescript is useful here**
- Suppose you accidentally write:
```tsx
<User name="tharun" age="23" city="nandyal" />
```
- This complains ts beacuse the type of age is number but we gave string.
- **Props are inputs to component.**
