#### JSX Expressions + Dynamic Data

- We'll make those components display dynamic typescript values.
- JSX can use JavaScript/TypeScript expressions, use {};
```tsx
function App(){
    const name = "Tarun";
    return <h1>Hello {name}</h1>;
}
export default App;
```

**You can use expressions**
```tsx
function App(){
    const age = 23;
    return (<div>
    <h1>My name is Tarun</h1>
    <p>Age: {age}</p>
    <p>Next Year: {age+1}</p>
    </div>);
}

export default App;
```
- JSX {} expects an expression.

**Typescript works normally**
```tsx
function App() {
    const name: string = "tharun";
    const age: number = 23;
    const isStd: boolean = true;

    return(
        <div>
            <h1>{name}</h1>
            <p>{age}</p>
            <p>{isStd ? "yes" : "no"}</p> //conditional  expression
        </div>
    );
}

export default App;
```

**JSX expressions can call functions**

```tsx
function App() {
    const getName = () =>{
        return "Tharun";
    };
    return <h1>Hello {getName()}</h1>;
}

export default App;
```

**Important distinction**
- we can put values inside JSX like:
- <h1>{name}</h1> <p>{age}</p>
- But don't put normal statements directly inside JSX:
- <h1>{if (age > 18)}</h1> // wrong way
