#### Derived data and Filtered Lists

- Don't create state for data that can be calculated from existing state.

```tsx
type Product = {
    id: number;
    name: string;
    price: number;
};

const products: Product[] = [
    {id:1,name: "Laptop", price: 50000},
    {id:2,name: "Phone", price: 25000},
    {id:3, name: "Tablet" price: 32000},
    {id:4, name: "PowerBank", price: 1500},
    ];
```
- Suppose we want only  products cheaper than price 30000
- We can calculate
```tsx
const affordableProducts = products.filter(product => product.price < 30000); // list of affordable
```
- Then render it.
```tsx
{affordableProducts.map(product => (<p>{product.name} - ₹{product.price}</p>))}
```
- This is fine if we have fixed data and no need to change that again and render if we want then we should store that data inside state then only we can update data or add data or anthing.

**Dervied data from state**
- This becomes especially useful with state:
```tsx
type Product = {
    id: number;
    name: string;
    price: number;
};
const [products, setProducts] = useState<Product>([
    {id:1,name: "Laptop", price: 50000},
    {id:2,name: "Phone", price: 25000},
    {id:3, name: "Tablet" price: 32000},
    {id:4, name: "PowerBank", price: 1500},
]);

const  affordableProducts = products.filter(product => product.price < 35000>);

{affordableProducts.map(product => (<p>{product.name} - ₹{product.price}</p>))}

```
- Every time products changes, React renders again and recalculates affordableProducts.

**Search Example:**
- This is where it becomes more realistic.
- We can have state for the users search:
```tsx
const [search, setSearch] = useState("");

const filteredProducts = products.filter(product => product.name.toLowerCase().includes(search.toLowercase()));
```
- Includes() is js method used to check weather a value exists inside a string or array.
- Dont put derived data in state.

**A useful Rule**
- we dont need another state varible derived from two states we can store that in variable.
- Instead of:
```tsx
const [firstName, setFirstName] = useState("");
const [lastName, setLastName] = useState("");

const fullname = `${firstName} ${lastName}`;
return(
    <div>
        <input type="text" placeholder={First Name} onChange={(e) => setFirstName(e.target.value)}>
        <input type="text" placeholder={Last Name} onChange={(e) => setLastName(e.target.value)}>
        <p>Hello, {fullname}</p>
    </div>
);


```
