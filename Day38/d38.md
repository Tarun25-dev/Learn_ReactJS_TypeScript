#### forwardRef - Passing a ref to a child component
- We already know about useRef and useLayoutEffect.
- Now, we learn about how to pass a ref from a parent component to an element inside a child component.
- This becomes more useful when a parent needs to control or measure something inside a reusable component.

**Problem**
- Suppose we have two components App and CustomInput(inside input tag containing ref).
- If App wants to focus that input, this won't work.
- A normal function component doesn't automatically forward that ref to its internal <input>.
- Thats what forwardRef is for.

**Create a child component with forwardRef**
```tsx
import {forwardRef} from "react";
export const CustomInput = forwardRef<HTMLInputElement>(function CustomInput(_, ref){
    return(
        <>
        <input ref={ref} className="rounded border px-3 py-2" placeholder="Enter your Name"/>
        </>
    );
})
```
- underscore(_) is just a variable name for parameter, developers use when they receive an argument but don't need to use it.
- _ first argument not needed.
- ref second argument needed.

**Using it from the parent**
```tsx
import CustomInput from "./ForwardRef";
import useRef from "react";

function App(){
    const inputRef = useRef<HTMLInputElement>(null);

    function handleFocus(){
        inputRef.current?.focus();
    }
    return(
        <>
        <CustomInput ref={inputRef} />
        <button onClick={handleFocus}>Focus Input</button>
        </>
    );
}
```
**Where is this useful?**
- You'll see this pattern with reusable components such as:
- CustomInput
- CustomButton
- Modal
- Dropdown
- DatePicker
- Tooltip
