#### React Router

**Routing**: A router lets a React application show different UI beased on the URL without doing a full browser page reload.
- Current React Router uses the `react-router` package  including BrowserRouter, Routes, Route, and Link.

**Install React Router**
- Open the Project folder and open terminal in that path

```cmd
npm install react-router
```

**What is routing?**
- Without routing: http://localhost:5173/ 
- With routing: http://localhost:5173/Home or http://localhost:5173/About or http://localhost:5173/Contact, etc.
- So the URL determines which component is displayed.

**BrowserRouter**
- Open your main.tsx, you'll probably have:
```tsx
import {StrictMode} from "react";
import {createRoot} from "react-dom/client";
import "./index.css";
import App from "./App";

createRoot(document.getElementById("root")!).render(
    <StrictMode>
        <App />
    </StrictMode>
);
```
- Change it to:
```tsx
import {StrictMode} from "react";
import {createRoot} from "react-dom/client";
import {BrowserRouter} from "react-router";
import "./index.css";
import App from "./App";


createRoot(document.getElementById("root")!).render(
    <StrictMode>
        <BrowserRouter>
            <App />
        </BrowserRouter>
    </StrictMode>
);
```
- BrowserRouter uses the browsers history API to enable client side routing.

**Routes and Route**
- Now open App.tsx
```tsx
import {Routes, Route} from "react-router";
```
- Create some pages:
```tsx
function Home(){
    return <h1>Home Page</h1>;
}

function About(){
    return <h1>About Page</h1>;
}

```
- Then:
```tsx
function App(){
    return(
        <Routes>
           <Route path="/" element={<Home />} />
           <Route path="/about" element={<About />} />
        </Routes>
    );
}
```
- http://localhost:5173/ -> Home page and loads only home component.
- http://localhost:5173/about -> About page and loads only above component.

**Link**
- Now we need a way for the user to navigate. We could use html tag <a href="./abour">About</a>
- But React Router provides: <Link>
```tsx
import  {Link} from "react-router";

<nav>
    <Link to="/">Home</Link>
    <Link to="/about">About</Link>
</nav>
```
- When we click on Home or About that changes the route without requiring a traditional full-page navigation.
- Link is one of the React Routers declartive navigation APIs.

**Route**: defines what should be displayed for a URL. like when user visits this url then load and show this component.
**Link**: lets the user navigate to that URL.like when user clicks url changes and automatically shows its component.

- Routes: It is a container that finds the matching route.
- Route: one individual routing rule.
- Link: navigation element and moves the user between those routes.
