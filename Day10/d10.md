#### Updating state correctly with the previous state

- We have learned:
```tsx
const [count, setCount] = useState(0);
```
- We learn this pattern that is important pattern and we'll use constantly in React:
```tsx
setCount(prevCount => prevCount + 1);
```
**The problem**
```tsx
<button onClick = {() =>{
    setCount(count+1)
}}>Increase</button>
```
- This works when you're simply updating from the current value.
- But sometimes your new state depends on the previous state.
- For that react provides the functional updater form:
```tsx
setCount(prevCount => prevCount + 1);
```
**Example**
```tsx
function App(){
    const [count, setCount] = useState(0);
    function increase(){
        setCount(prevCount => prevCount + 1);
    }
    return(
        <div>
        <p>Count: {count}</p>
        <button onClick = {increase}>Increase</button>
        </div>
    );
}

export default App;

```
- So each update receives the result of the previous update.

**Why this useful**
- Imagine you want to increase the count multiple times in one event:
```tsx
function increaseThreeTimes(){
    setCount(prev => prev + 1); // 1
    setCount(prev => prev + 1); // 2
    setCount(prev => prev + 1); // 3
}
```
- This pattern is normal way just we leanerd that prev day.
- Previous state updater solves that problem.
- This is much safer when the next state depends on the previous state.

**Current value VS Previous Value Updater**

- **Current Value:** setCount(count + 1); 
- Set the state to the current count + 1.
- **Previous state updater:** setCount(prevCount => PrevCount + 1);
- Take the latest previous state and calculate the next state from it.
- And typescript infer its type automatically.

**We can also do it for strings**
```tsx
const [name, setName] = useState("tharun");
setName(prevName => prevName.toUpperCase());
```
- Typescript knows prevName is string beacuse ("tharun") and then it will confirms its prevName is valid.
- current state = "tharun"
- New state = "THARUN"
- If your new state depends on the previous state, use the functional updater form.

**Task**
```tsx
function App(){
    const [count, setCount] = useState(0);
    function IncreaseFive(){
        setCount(prev => prev + 5);
    }
    return(
        <div>
            <button onClick = {IncreaseFive}>+5</button>
        </div>
    );
}
```
