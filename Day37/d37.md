#### useLayoutEffect

- We already used useEffect now we will learn how to use useLayoutEffect.

**useEffect**
```text
useEffect
    ⬇️
React updates Dom
     |
Browser paints
     |
Effect Runs
```
- Browser paints means the moment when the browser actually draws pixels on your screen.
- So initial rendering useEffect remains hidden. so it doesn't make any change to the initial UI.

**useLayoutEffect**
```text
useLayoutEffect
    ⬇️
React updates Dom
     |
useLayoutEffect
     |
Browser paints
```
- So useLayoutEffect runs synchronously after the DOM update but before the browser paints.

```tsx
function App(){
    const boxRef = useRef<HTMLDivElement>(null);
    const [width, setWidth] = useState(0);

    useLayoutEffect(() => {
        if(boxRef.current){
            setWidth(boxRef.current.getBoundingClientRect().width);
        }
    }, []);
    return(
        <div>
        <div ref = {boxRef} className="w-64 h-32 bg-blue-500">Box</div>
        <p>Width: {width}px</p>
        </div>
    );
}
```
- boxRef.current.getBoundingClientRect().width;
- boxRef.current.getBoundingClientRect() is used to find the exact size and position of an HTML element relative to the browsers viwport including width property.
- boxRef.current.getBoundingClientRect().width; we extract width from that element.

**Why not simply use useEffect?**
- Imagine you need to:
- Render an element
- Measure its position
- Immediately adjust something based on that meansurement.

- with useEffect the browser may paint the first version before your meansurement/update happens.

**Tooltip**
- A tooltip is a small piece of information that appears near an element when the user interacts with it, usually by hovering, focusing or sometimes clicking.
- Tooltip position is the screen coordinates where that message/info is displayed.
- Tooltip is like a temporary label
- Example: when hover the button then display lebel to show what actually dutton/element does.

**Practical example:**
```text
render button
    |
Measure button position
    |
Calculate tooltip position
    |
Position tooltip
    |
Browser paints
```
- useLayoutEffect is suitable for this kind of work.

```tsx
function App(){
    const buttonRef = useRef<HTMLButtonElement>(null);
    const [showTooltip, setShowTooltip] = useState(false);
    const [tooltipPosition, setTooltipPosition] = useState({top:0, left:0});

    useLayoutEffect(() => {
        if(!showTooltip) return;

        const rect = buttonRef.current?.getBoundingClientRect();
        // calculate tooltip position
        if(!rect) return;
        const top = rect.bottom + 8; //acctual button position bottom with increase of 8px.
        const left = rect.left; // actual button left position is same as tooltip position.

        setPosition({
            top,
            left
        });
    }, [showTooltip]);
    return(
        <div>
            <button ref={buttonRef} onMouseEnter={() => setShowTooltip(true)} onMouseLeave={() => setShowTooltip(false)}>Delete</button>
            {showTooltip &&  (<div className="fixed bg-blue-500 px-3 py-2 text-white text-sm" style={{top: tooltipPosition.top, left:tooltipPosition.left}}>Delete Element tooltip</div>)}
        </div>
    );

}
```

**When should you use it?**
- Measuring element dimensions.
- Reading element position
- positioning tooltips/popovers
- Preventing visual flickering during layout changes.
- DOM meansurement that  must happen before paint.
