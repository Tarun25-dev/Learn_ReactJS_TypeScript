#### Context + State
- We already learned about create data and sharedata using createContext and useContext.
- Now we'll make that shared data changeable.

- Instead of putting a fixed value like: <UserContext.Provider value="Tharun">
- We'll keep the user in state.
```tsx
type User = {
    name: string;
    role: string;
};

const UserContext = createContext<User | null>(null);
```
- The null is important beacuse initially there may be no user.
- Keep the state in the provider
```tsx
function App(){
    const [user, setUser] = useState<User | null>({
        name: "Tharun",
        role: "React developer"
    });
    return(
        <UserContext.Provider value={user}>
            <Profile />
        </UserContext.Provider>
    );
}
```
- Now Profile can read it:
```tsx
function Profile(){
    const user = useContext(UserContext);
    if(!user){
        return <p>Please Login, No User Found<p>
    }
    return(
        <div>
            <h2>{user.name}</h2>
            <p>{user.role}</p>
        </div>
    );
}
```
**Changing the Context value:**

```tsx
type UserContextType = {
    user: User | null;
    setUser: React.Dispatch<SetStateAction<User | null>>;
};

const userContext = createContext<UserContextType | null>(null);

<UserContext.Provider value={{user, setUser}}>
<Profile />
</UserContext.Provider>
```
- setUser property must be a function that can change user to either a User object or null.
- Now Profile can handle both Read and change the shared state.
```tsx
<button onClick = {() => setUser({name:"Kumar",role:"Typescript developer"})}>Role change</button>
```
