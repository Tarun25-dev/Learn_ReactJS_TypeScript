#### Nested Routes
- Nested routes are useful when one page has its own sub pages.
- Think of a movie application:
```text
/movies
    |
Movie Page
    |____/movies/1
    |____/movies/2
    |____/movies/3
```
- Or a dashboard:
```text
/dashboard
    |___ /dashboard/profile
    |___ /dashborad/settings
    |___ /dashboard/orders
```

**Parent Route:**
```tsx
<Route path="/movies" element={<Movies />}>
```
- Then inside the Movies route we can have child routes.

**Outlet**
- React Router gives use <Outlet />
- `import {Outlet} from "react-router";`
- Outlet tells React Router to render the matched child route here.

**Example**
```tsx
function Movies(){
    return(
        <>
        <h1>Movies</h1>
        <nav>
            <Link to="1">Movie 1</Link>
            <Link to="2">Movie 2</Link>
        </nav>
        <Outlet />
        </>
    );
}

function MovieDetails(){
    return(
        <>
        <h1>Movie Details</h1>
        <p>You are viewing a movie</p>
        </>
    );
}

function App(){
    return(
        <>
            <Routes>
                <Route path="/movies" element={<Movies />} />
                <Route path=":movieId" element={<MovieDetails />}>
            </Routes>
        </>
    );
}
```

**Why Outlet?**
- when the url is /movies/1 then react router renders movieDetails and movieDetails appears exactly where we placed outlet component.

**Nested Routes are Perfect fro layouts**
- This is the one of thier biggest real-world uses.
- Imagine a sidebar:
```text
Dashboard
 _______________________________________________
|                             |                 |
-----Sidebar                  |     <Outlet />  |
|                             |                 |
|    Home                     |                 |
|    Profile                  |                 |
|    Settings                 |                 |
|                             |                 |
|_____________________________|_________________|
```
- The sidebar stays visible only the content inside <Outlet /> changes.
- We don't have to duplicate the sidebar on every page.
