#### useRef - for previous values

- We know that ability to remember the previous value of something.
**Remembering the previouse value**
```tsx
function App(){
    const [count,setCount] = useState(0);
    const prevCount = useRef<number | undefined>(undefined);

    useEffect(() => {
        prevCount.current = count;
    }, [count]);
    return(
        <div>
            <p>Current: {count}</p>
            <p>{PrevCount.current}</p>
            <button onClick = {() => {
                setCount(prev => prev+1);
            }}>Increase</button>
        </div>
    );
}

```
- But there is Important to know that first setCount will renders before effect so what effect, so during that render":
- So React renders all components first and then useEffect runs after that render so that value is undefined to 0.
- first render: count: 1, prevCount: 0
- Thats exactlt what we want.
- The ref stores the value from the previous render until the next render occurs.
