#### Handling Multiple Inputs with One handler

```tsx
type FormData={
    name: string;
    email:string;
};

function App(){
    const [form, setForm] = useState<FormData>({name: "", email:""});
    return(
        <div>
            <form>
            <input name="name" value={form.name}/>
            <input name="email" value={form.email}/>
            </form>
        </div>
    )
}

```
**One Handlechange**
```tsx
function handleChange(event: ChangeEvent<HTMLInputElement>){
    const {name, value} = event.target;
    setForm(prev => ({
        ...prev,
        [name]: value,
    }));
}
```
- Important is [name]: value
- suppose the user changes the name input then name = "name" and value = "tharun"
- event.target collects which input element is calling this event so form that we doing destructuring.
- According to the input which element changed then that element name attributes used if email chagnges then name = "email" and value = {event.target.value
- It simple works like event.target.name to find which property either name or email
- event.target.value to find that changed value.
