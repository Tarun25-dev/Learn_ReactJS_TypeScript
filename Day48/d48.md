#### Dynamic routes + URL parameters

- We already learned about basic routes like /,/about,/contact, etc.
- Now we'll make routes dynamic.
- For example a movie website might have:
```text
/movies
/movies/101
/movies/205
/movies/350
```
- Instead of creating a seperating route for every movie, we create one dynamic route.

**Dynamic route**
- Suppose we have: /movies/:movieId
- : means movieId is a dynamic url parameter
**create**
```tsx
<Route path="/movies/:movieId" element={<MovieDetails />}>
```
- Now all of Ids can match 

**Getting the parameter**
- React router provides: useParams()
- import {useParams} from "react-router";
```tsx
function MovieDetails(){
    const {movieId} = useParams();

    return(
        <h1>Movie Id: {movieId}</h1>
    );
}
```
- if the url is /movies/101 
- you get movieId = "101"
- Notice that url parameters are strings, and if we need a number then 
- const id = Number(movieId);

**example**
```tsx
import {Link, Route, Routes, useParams} from "react-route";

function Home(){
    return(
        <>
        <h1>Movies</h1>
        <div>
        <Link to="/movies/101">Movie 101</Link>
        <Link to="/movies/205">Movie 205</Link>
        </div>
        </>
    );
}

function MovieDetails(){
    const {movieId} = useParams();
    return(
        <>
        <h1>Movie Deatails</h1>
        <p>Movie ID: {movieId}</p>
        </>
    );
}

function App(){
    return(
        <>
        <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/movies/:movieId" element={<MovieDetails />}>
        </Routes>
        </>
    );
}
```
