#### useEffect Running side Effects

- Today we need to learn another react hook called useEffect after the useState.

**What is a Hook?**
- A Hook is a special function that lets a functional component use react features such as state, side effects, context, refs.
- **useState** = store and update component data.
- **useEffect** = Run code when something happens / changes.

**What is a side Effect?**
- A side effect is an operation that interacts with something outside the component's rendering calculation.
- Common examples:
- Fetching API data
- Updating the document title
- Starting a timer
- Listening for browser events
-Working with local storage

```tsx
import {useEffect, useState} from "react"

function App(){
    const [count, setCount] = useState(0);
    useEffect(() =>{
        console.log("Effect Ran");
    });
    return(
        <div>
        <p>Count: {count}</p>
        <button onClick={() => {
            setCount(prev => prev + 1);
        }}>Increase</button>
        </div>
    );
}

```
- Every time the component renders, the effect runs.
- So initially render -> useEffect, state changes -> render again -> useEffects runs again.

**Empty dependency array**
- Usually we don't want an efffect to run after the every render.
- We can give it a dependency array.
```tsx
useEffect(() => {
    console.log("Effect ran");
}, []);
```
- [] the empty array and this effect doesn't depend on any changing value.
- [] means run this effect only after the components first render(mount), not after every re-render.
- So it restricts the effect with mount.

**With a dependency**

```tsx
useEffect(() => {
    console.log("Name Changed");
},[name]);
```
- What it means Runs after the initial render and whenever name changes then the effect will run only.
- So we can decide that effect how to run and when to run depending on our needs.

```text
useEffect(fn) -> every render
useEffext(fn, []) -> initial mount
useEffect(fn, [x]) -> when x changes
```

- For example fetching initial data
```tsx
useEffect(() => {
    fetchUsers();
}, []);
```
- We don't want fetchUsers() running every time your components re-renders.

**Real Example**
- When we renders the total file we only want to render the title of our document only once and after any re-renders happens by events or something that title not be re-render again.
- So useEffect reduces the load on browser while re-rendering.
```tsx
useEffect(() => {
    document.title = "My portfolio App";
}, []);
```
- document.title controls the browsers tab's title.
