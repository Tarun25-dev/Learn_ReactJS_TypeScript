#### Conditional Rendering

- By condtional rendering we'll learn how to show different UI depending on a condition.

**Using a ternary operation**
```tsx
const [isLoggedIn, setIsLoggedIn] = useState(false);
```
- We can display different content:
```tsx
{isLoggedIn ? <p> Welcome Back </p> : <p>Please Login</p>}
```
- Full example:
```tsx
function App(){
    const [isLoggedIn, setIsLoggedIn] = useState(false);
    return(
        <div>
            {isLoggedIn ? <p> Welcome Back </p> : <p>Please Login</p>}
            <button onClick = {() => {
                setIsLoggedIn(prev => !prev); //!prev is opposite of prev
            }}>{isLoggedIn ? "logout" : "login"}</button>
        </div>
    );
}
```
**Using &&**
- Sometimes you only  want to show something when a condition is true.
```tsx
const isLoggedIn = true;
{isLoggedIn && <p>You are logged page</p>};
```

**Conditional rendering**
- You can calculate something before the return.
```tsx
function App(){
    const isLoggedIn = true;

    let message;

    if (isLoggedIn){
        message = <h2>Welcome</h2>
    } else {
        message = <h2>Please Login</h2>
    }
    return <div>{message}</div>;
}
```
- This is useful when the condition becomes more complicated.

**Conditional Rendering with  Data**
```tsx
type User = {
    name: string;
};

function App(){
    const user: User | null = {
        name: "Tharun",
    };
    return(
        <div>
            {user ? (<h2>Hello, {user.name}</h2>) : (<h2>No User Found</h2>)}
        </div>
    );
}
```
// We know that  null is a falsy value if name is null then else statement executed.
