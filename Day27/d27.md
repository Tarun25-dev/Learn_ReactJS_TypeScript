#### useContext - Sharing Data Without Prop Drilling

- We already know that props and lifting state up
- Now imagine: App -> Navbar -> UserName -> Profile
- If Profile needs the user name you would have to pass it through every component:
- App -> Navbar -> UserMenu -> Profile
- This is called a prop drilling, even though some of the components not needed though that props will pass through it.

**Create a Context**
- createContent.tsx

```tsx
import {createContext, useContext} from "react";

export const UserContext = createContext<string>("");
```
- Here we created a context that stores a string.

**Provide the Value**
```tsx
function App(){
    return(
        <UserContext.Provider value="Tharun">
        <Navbar />
        </UserContext.Provider>
    );
}
```
- Inside the provider can access "Tharun".

**Read the value**
- Even if Profile is deeply nested:
```tsx
function Profile(){
    const user = useContext(UserContext);
    return <h2>Hello {user}</h2>
}
```
- If we want that in profile component:
- in App.tsx
```tsx
function App(){
    return(
        <UserContext.Provider value="Tharun">
        <Navbar />
        <Profile />
        </UserContext.Provider>
    )
}
```
- We can use that context in navbar as well as profile component.
```tsx
function Profile(){
    const profileName = useContext(UserContext);
}
```
**Practice**
- userContext.tsx

```tsx
import {createContext, useContext} from "react";

type User = {
    name: string;
    role: string;
};
export const UserContext = createContext<User>({name:"",role:""});
function UserContextComponent(){
    return(
        <div>
        <p>This page holds the context of useContext</p>
        </div>
    );
}
```
- We need to set that context what elements wants that UserContext in App.tsx
```tsx
import {UserContext} from "./UserContextComponent";

function App(){
    <UserContext.Provider value={name:"Tharun", role: "React Developer"}>
        <Profile />
    <UserContext.Provider>
}
```

- Then share data to display it in profile:
```tsx
import useContext from "react";
import {UserContext} from "./UserContextComponent";

function Profile(){
    const profile = useContext(UserContext);
    return(
        <>
        <p>Name: {profile.name}</p>
        <p>Role: {profile.role}</p>
        </>
    );
}

```
