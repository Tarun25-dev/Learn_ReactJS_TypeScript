#### useReducer - Managing complex state

- We know very well about useState and we will learn another way to manage state:
- useReducer is especially useful when state has multiple related actions.
- syntax: **useReducer(reducer, initialState)**
- instead of:
```tsx
const [count,setCount] = useState(0);
```
- We can use: 
```tsx
import useReducer from "react";
function reducer(state: number, action: string){
    if(action === "increase"){
        return state + 1;
    }
    if(action === "decrease"){
        return state - 1;
    }
    return state;
}


function App(){
    const [count, dispatch] = useReducer(reducer, 0);

    return(
        <>
        <p>Count: {count}</p>
        <button onClick={() => dispatch("increase")}></button>
        <button onClick={() => dispatch("Decrease")}></button>
        </>
    );
}
```
- count when we need to change then that decide reducer function by dispatch.
- dispatch("increase") means we are setting a new state but indirectly we send that action info "increase" to the reducer.
- inside that that function returns the new state to the count and renders that ui.

**Use a proper action**
- instead of something like in if-condition in the previous code.
- we use union:
```tsx
type Action = 
    |{type: "increase"}
    |{type: "decrease"}
    |{type: "reset"};
```
- This is called discriminated union and It means Action can be one of these three object shapes.
- Why each object has its own type beacuse type is the label that tells to the reduer what action actually happend.
- each action has its own type like "increase" is a string but ts allows only one these three are valid for the reducer and now other actions are allowed.
- Now the reducer:
```tsx
function reducer(state: number, action: Action){
    switch(action.type){
        case "increase":
            return state + 1;
        case "decrease":
            return state - 1;
        case "reset":
            return 0;
    }
}

function App(){
    const [count,dispatch] = useReducer(reducer,0);
    return(
        <>
        <p>Count: {count}</p>
        <button onClick = {() => dispatch("increase")}>Increase</button>
        <button onClick = {() => dispatch("decrease")}>Decrease</button>
        <button onClick = {() => dipatch("reset")}>Reset</button>
        </>
    );

}
```
**Why use an object fro the action?**
- Beacuse later an action can carry data.
- for example:
```tsx
{type: "Increase"; amount: number}
```

**Action + Data**
- For example suppose we want to increase the count by a specific number:
```tsx
type Action = {
    type:"increase";
    amount: number;
}

function reducer(count: number,action: Action){
    if(action.type === "increase"){
        return count + action.amount;
    }
    return count;;
}

function App(){
    const [count,dispatch] = useReducer(reducer,0);
    return(
        <>
        <p>Count: {count}</p>
        <button onClick = {() => dispatch({count:"increase",amount: 5})}>Increase</button>
        </>
    );
}
```
