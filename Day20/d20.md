#### Rendering Lists and key 

**Rendering an array**
```tsx
const users = ["tharun","kumar","nani"];

{users.map(user => (<p>{user}</p>))}
```
- But react will warn "Each child in a list should have a unique "key" prop.
**What is key?**
- The key  helps react identify which list item is which.
```tsx
{users.map((user) => (<p key={user}>{user}</p>))}
```

**Objects are better**
- In real applications your data normally looks like:
```tsx
type User = {
    name: string;
    id: number;
};
const users: User[] = [
    {name:"Tharun", id:3225},
    {name:"Kumar", id:3226},
    {name:"Nani", id:3227},
    {name:"Rahul", id:3228},
];

{users.map((user) => (<p key={user.id}>{user.name}</p>))}
```
- Important is : key is not available as a normal prop like function user(key,name); wrong
