#### Fetching Data with useEffect
- Like fetching data from an Api and displaying it in your component.

**The basic Idea**
- Component renders -> useEffect runs -> Fetch API -> receive data -> setState(data) -> Component renders again -> Display data.

- Create the type for the Api data:
- For practice, we'll use a fake API.
```tsx
type User = {
    id: number,
    name: string,
    email: string;
};
```
- Then create the state:
```tsx
const [users, setUsers] = useState<User[]>([]);
```
- initially users = [], empty array
- Fetch inside useEffect:
```tsx
useEffect(() => {
    async function fetchUsers(){
        const response = await fetch("https://jsonplaceholder.typicode.com/users");
        const data: User[] = await response.json();
        setUsers(data);
    }

})
```
- **Important:** Don't Do like `useEffect(async () =>{}, [])` and instead write like: `useEffect(() => {async function fetchUsers(){}}, [])`
- Beacuse, The useEffect callback iteself shouldn't be made async.

- fetch() sends a request to the URL and waits for the server to respond.
- the result stored in response is a Response object.
- It contains information about the http response. in that object mainly we need to focus on status and body.
- status give something like status: 200 the it will successfully fetch the data from API.
- body contains what we request to the Api.

- response.json() reads the body of the response and converts the JSON into a JavaScript value.
- Suppose the server sends:
```json
{
    "name": "Tharun",
    "role": "Developer"
}
```
- Then after reponse.json()
```js
data = {
    name: "Tharun",
    role: "Developer"
};
```
- Display the users
```tsx
return(
    <>
    <h1>Users</h1>
    {users.map(u) => {
        <div>{user.name}</div>
        <p>{user.email}</p>
    }}
    </>
);
```
- Add loading state
- Real applications shouldn't just show an empty screen while waiting.
```tsx
const [loading. setLoading] = useState(true);

useEffect(() => {
    async function fecthUsers(){
        const response = await fetch("https://jsonplaceholder.tyicode.com/users");
        const data: User[] = await response.json();

        setUsers(data);
        setLoading(false);
    }
    fetchUsers();
}, []);
```
- And any loading element to show like:
```tsx
if(loading){
  return <p>Loading...</p>;
}
```

- Add error handling
- Sometimes network requests can fail.
````tsx
const [error, setError] = useState<string | null>(null);

useEffect(() => {
    async function fecthUsers(){
        try{
        const response = await fetch("https://jsonplaceholder.tyicode.com/users");

        if(!response.ok){
            throw new Error("Failed to fetch users");
        }

        const data: User[] = await response.json();
        setUsers(data);

        } catch {
            setError("Something went wrong");
        } finally {
        setLoading(false);
        }
    }
    fetchUsers();
}, []);
```
- Then dispaly error:

```tsx
if (error) {
    return <p>{error}</p>;
}
```
