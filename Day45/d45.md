#### React Portals with createPortal

**What is Portal?**
- A portal lets you render a component into a different DOM location while keeping it inside the same react tree.
- This is especially useful for:
- Modals
- Dialogs
- Tooltips
- Dropdowns
- Toasts

**The basic idea:**

- Normally react tree looks like:
```text
React tree          DOM

App
#root               
 |_____Modal
|_____App
      |___div
|_____Modal
```
- With a Portal:
```text
React tree                   DOM

App
#root
 |____Modal
|____App
                              |
|____Modal
```
- The React relationship doesn't change. Only the DOM loaction change.
- **Modal:** A modal is a UI element that appears on top of the current page and usually requires the user to interact with it before continuing.
- Typical Examples: Login Popup, Delete Confirmation, Image viwer, Payment dialog, settings dialog, etc.
- A modal is not a special type of DOM, its simply a UI pattern.

- We cant put that model along with its normal layout UI of parent thats where Portals concept comes in.
- Those Modal can rendered through a seperate DOM location.


**Why need to keep a Modal into seperate DOM location?**
- Beacuse a modal often needs to visually escape the normal layout of its parent.
- Event though our modal had CSS properties like position: fixed; z-index: 9999; 
- Even though the parent css can sometimes interfere with it.
- Example: 
```text
DOM
|____Dashboard container
    |____Header
    |____Content
    |____Modal
```
- The modal is still inside the Dashboard container, so its positioning and stacking can affected by that container.
- With Portal
```text
DOM
|______#root
|      |____Dashborad container
|           |___Header
|           |___Content
|______#modal-root
      |____Modal
```
- Now the modal is near the top of the DOM so it can more easily cover the entire page.

**CreatePortal**
```tsx
import {createPortal} from "react-dom";
```
- Basic syntax:
```tsx
createPortal(
    <div>Hello</div>,document.body
);
```
- The first argument is what to render.
- The second argument is where to render it.

**Example:**
- Modal.tsx
```tsx
function Modal({onClose:() => void}){
    return createPortal(
        <>
        <h2>Delete Account</h2>
        <p>This action cannot be undone.</p>
        <button onClick={onClose}>Cancel</button>
        <button onClick={onClose}>Delete</button>
        </>,document.body
    );
}
```
- App.tsx
```tsx
function App(){
    const [isOpen, setIsOpen] = useState(false);
    return(
        <>
        <button onClick={() => setIsOpen(true)}>Open Modal</button>
        {isOpen && (<Modal onClose={() => setIsOpen(false)}>)}

        </>
    );
}
```
