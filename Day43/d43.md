#### React.lazy + Suspense

- Now we will learn code spliting or lazy loading.
- Instead of loading every component when the application starts, we can load a component only when react needs it.
- This is especially useful when an application has larger pages or components that aren't needed immediately.

**Normal Import:**
```tsx
import About from "./About";
```
- This component is included in the initial js bundle.

**With lazy loading**
```tsx
const About = lazy(() => import("./About"));
```
- React can load About when it's needed.

**React.lazy**
- It is a method/function.

```tsx
import {lazy} from "react";
```
- Then
```tsx
const About = lazy(() => import("./About"));
```
- This is called **dynamic import.**
- It returns a Promise beacuse the module is loaded asynchronously.

**Why do we need Suspense?**
- While the component is being loaded, React needs something to display.
- Thats what Suspense provide.
```tsx
import {lazy, Suspense} from "react";

<Suspense fallback={<p>Loading...</p>}><About /></Suspense>

```
- Think like Need about -> start loading about -> not ready yet -> show fallback -> anout loaded -> show about

**Why suspense is necessary**
- Beacuse About isn't immediately available beacuse:
- import("./About") -> Promise -> module loads -> Component becomes available.
- While that Promise is pending react needs a fallback.

**Real analogy:**
- Suppose we have components like Home, Movies, Movie Details, Settings, Admin.
- So initially user visits Home page so no need to load other components.
- whenever user clicks on movies button then movies component gets Promise and loads that component and shoows all movies so until it shows movies there is only active Suspense fallback only.

- lazy = Loads a component asynchronously
- Suspense = shows fallback while something is loading.

**UseCases**
- Large pages
- Large feature sections
- Rarely visited screens
- Heavy components

**Example:**
- About.tsx
```tsx
function About(){
    return(
        <>
        <h2>About Page</h2>
        <p>This is the About Page.</p>
        </>
    );
}
export default About;
```
- App.tsx
```tsx
import {lazy, Suspense, useState} from "react";
const About = lazy(() => import("./About"));

function App(){
    const [showAbout, setShowAbout] = useState(false);
    return(
        <>
        <nav>
        <button onClick={() => setShowAbout(true)}>About</button>
        </nav>
        <main>
        {showAbout && (<Suspense fallback={<p>Loading About...</p><About /></Suspense>}>)}
        </main>
        </>
    );
}
```
- Now About isn't rendered until setShowAbout(true) and its code can be loaded seperately.
