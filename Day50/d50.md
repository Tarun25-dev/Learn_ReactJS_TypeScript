## **Understanding API requests:**

A React application often needs data from a backend.

The flow is:

React → HTTP request → Backend/API → HTTP response → React → Display data

The most common HTTP methods are:

| Method | Purpose |
|--------|---------|
| GET    | Get data |
| POST   | Create data |
| PUT    | Update data |
| PATCH  | Partially update data |
| DELETE | Delete data |

### fetch()
JavaScript provides fetch() to make HTTP requests.

Basic example:

fetch("https://example.com/api/items")

But fetch() is asynchronous, so we normally handle it with async/await:

const response = await fetch("https://example.com/api/items");
const data = await response.json();
