#### Component with tsx

- A react application is built from components.
- A component in react is a reusable, independent piece of UI.
- With typescript, we'll write our components in .tsx files.

- First component
```tsx
function App(){
    return <h1>Hello, React + Typescript</h1>;
}

export default App;
```
- Thats the react component.
- It is a normal typescript function that returns JSX.

**Component names**
- React components should normally start with an uppercase letter.
- Beacuse to distinguish your components from HTML elements.

```tsx
function User(){
    return <h2>Tarun</h2>;
}

export default User;
```
