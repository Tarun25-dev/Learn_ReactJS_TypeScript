#### useEffect Cleanup
- We already knoow that  when an effect runs and how the dependency array works.
- Now we need to learn how to clean up something that an effect started.
- This becomes important withh timers, event listeners, subscriptions, and other resources.

**A timer inside useEffect**
```tsx
import {useEffect} from "react";

function App(){
    useEffect(() => {
        const timer = setInterval(() => {
            console.log("Timer Running");
        },5000);
        return () => {
            clearInterval(timer);
        };
    }, []);

    return(
        <h1>Timer Explanation</h1>
    )
}
```
- const timer = setInterval(...) is starts something 
- returns clearInterval(timer) it clears that  time running.

**Why do we need this?**
- Imagine the component that starts with timer:
- Component appears -> setInterval starts -> timer keeps running.
- Later the component is removed.
- If we don't clean up running then component removed but timer may  still running and unnecessary work.
- If we clean up running then component removed cleanUp function runs and clearInterval() and Timer stops.

**The cleanup function?**
```tsx
useEfect(() =>{
    // start something

    return () => {
    // clean it up
    }
});
```
- The function returned from the effect is called the cleanup function.

**CleanUp with Dependencies change**
- Cleanup is not only for when a component disappears.
```tsx
useEffect(() => {
    console.log("Effect  started");

    return () => {
        console.log("cleanup");
    };
}, [count]);
```
```text
useEffect runs
    |
"Effect started"
    |
React receives the cleanup function
    |
[count changes]
    |
React calls the cleanup function
    |
"cleanup"
    |
New effect runs
```
- Cleanup isn't necessarily something you want to do immediately. You want react to do it when the effect needs to be cleaned up.

**Real Example: window event listener**

```tsx
import {useEffect} from "react";
function App(){
    useEffect(() => {
        function handleResize(){
            console.log(window.innerWidth);
        }
        window.addEventListener("resize",handleResize);

        return () => {
            window.removeEventListener("resize", handleResize)
        };
    }, []);
    return(
        <h1>Resixe the browser</h1>
    );
}
```
- If we resize the browser: Browser resized -> "resize" event happens -> handleResize runs.
- When effect is done then react calls the return function and cleanup that event.

```text

  | **Effect starts** |     **Cleanup**      |
  | _________________ | _________________    |
  |  setInterval()    |  clearInterval()     |
  |  setTimeout()     |  clearTimeout()      |
  | addEventListener()| removeEventListener()|
  --------------------------------------------
```
