#### Rendering Lists with .map()

- React uses map() to render multiple elements.

**Why map() in react?**
- Suppose we have 
```ts
const names = ["tharun","rahul","arun"];
```
- Instead of manually writing:
```tsx
<h2>Tarun<h2>
<h2>Rahul<h2>
<h2>Arun<h2>
```
- Reacts lets you generate them:
```tsx
function App(){
    const names = ["tharun", "rahul", "arun"];

    return (
        <div>
        {names.map((n) => (
            <h2>{n}</h2>
        ))}
        </div>
    );
}
export default App;
```
- Important pattern is: **{array.map((item) => (<element>{item}</element>))}**

**Important key Prop**
- you'll notice react gives a warning if you render a list without a key.
```tsx
function App(){
    const names = ["tharun", "rahul", "arun"];

    return (
        <div>
        {names.map((n) => (
            <h2 key={n}>{n}</h2>
        ))}
        </div>
    );
}
export default App;
```

**What is key?**
- key gives React a stable identity for each item in a list.
- Think like: Tarun -> key = "Tarun" or Rahul -> key = "Rahul".
- Here item itself acts a key for each element.
- React uses these keys to understand which list items were added, removed, or changed.

**Objects + Typescript**
- This is much closer to real react applications.

```tsx
type User = {
    id: number;
    name: string;
    age: number;
};

function App(){
    const users: User[] = [
        {id: 1,name: "tharun", age: 23},
        {id: 2,name: "rahul",age:32},
        {id: 3, name: "arun", age: 24}
    ];
    return(
        <div>
        {users.map((user) => (
            <div key={user.id}>
            <h2>{user.name}</h2>
            <p>Age: {user.age}</p>
        </div>
        ))}
        </div>
    );
}
export default App;
```
- Why we use key as id beacuse IDs are normally unique and stable.
- Avoid using the array index as key.
- key helps react to identify the element.

    id: number;

    price: number;
};

function App(){

        {id: 3, name: "laptop", age: 240000}
    ];
    return(
        <div>
            {products.map((product) => (
                <div key={product.id}>
                    <h4>{product.name}</h4>
                    <h5>{product.price}</h5>
                </div>
            ))}
        </div>
    );
}
export default App();
