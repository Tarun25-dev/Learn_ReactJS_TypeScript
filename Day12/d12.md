#### State with Arrays

- We will learn how to manage an array in state.
**Array state**
```tsx
function App(){
    const [todos, setTodos] = useState<todos[]>([
        {id:1,text:"learn ts"},
        {id:2,text:"learn react"}
    ]);
    return(
        <div>
            {todos.map((todo) => {
                <p key={todo.id}>{todo.text}</p>
            })}
        </div>
    )
}

```
- Typescript knows todos -> todos[] an array and no problem with type beacuse an arrays allows any type to  store.
**Adding an item**

- Suppose we want to add another todo.
- Use the spread operator.So the will be the new state.

```tsx
setTodos(prev => ([...prev,{id:3, text: "build a project"}]));
```
- Previous state: [A,B] => newState: [A, B, C];

**Complete Example:**
```tsx
function App(){
    const [todos, setTodos] = useState<todos[]>([
        {id:1,text:"learn ts"},
        {id:2,text:"learn react"}
    ]);
    function addTodo(){
        setTodos(prev => ([...prev,{id:3,text: "build a project"}]));
    }
    return(
        <div>
            {todos.map((todo) => {
                <p key={todo.id}>{todo.text}</p>
            })}
            <button onClick = {addTodo} >Add Todo</button>
        </div>
    )
}

```
**Removing an item**
- We can use filter method in array to remove unwanted elements in array.
```tsx
setTodos(prev => (prev.filter(todo => todo.id !== 2)));
```
- This means keep every todo whose ID is not 2.
- filter creates a new array containing only  the elements that satisfy a condition.
- map creates a new array by changing each element.
- but map is different from for each beacuse for each only performs action on each element but map perform an action in each element and returns it into a new array.

**Updating an item**

```tsx
setTodos(prev => prev.map(todo => todo.id === 1 ? {...todo,text:"learn react+typescript"} : todo));
```

**Practice**
```tsx
type Todo={
    id: number;
    text:string;
}

function App(){
    const [todo,setTodo] = useState<Todo[]>([
        {id:1,text:"react"},
        {id:2,text:"typescript"},
        {id:3,text:"javascript"}
    ]);
    function AddTodo(){
        setTodo(prev => ([...prev,{id:4,text:"typescript completed."}]));
    }
    function RemoveTodo(){
        setTodo(prev => prev.filter((todo) => todo.id !== 3));
    }
    function UpdateTodo(){
        setTodo(prev => prev.map(todo => todo.id === 2 ? {...todo,text:"ReactJS"} : todo));
    }
    return(
        <div>
            {todo.map((t) => {
                <p key = {t.key}>{t.text}</p>
            })}
            <button onClick = {AddTodo}>Add Todo</button>
            <button onClick ={RemoveTodo}>Remove Todo</button>
            <button onClick ={UpdateTodo}>Update Todo</button>
        </div>
    );
}

```
