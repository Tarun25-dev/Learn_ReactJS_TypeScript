#### useEffect cleanup functions

**What is cleanup?**
- Sometimes an effect starts something that should later be stopped or removed.
- Examples: 
- setInterval, setTimeout
- Event Listeners
- webSocket connections
- Subscriptions
- React lets you return a function from useEffect to clean it up.
```tsx
useEffect(() => {
    // start something

    return () => {
        // clean it up
    }
}, []);
```
