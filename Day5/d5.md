#### children Props

**What is children?**
- Look at this:
```tsx
<Card>
 <h2>Hello Tharun</h2>
 <p>Learning React</p>
</Card>
```
- The content inside <Card>...</Card> is called children.

**Type children with typescript**
- Card.tsx
```tsx
import type {ReactNode} from "react";

type CardProps = {
    children: ReactNode;
};

function Card({children}: CardProps){
    return (
        <div>
        {children}
        </div>
    );
}

export default CardProps;
```
- ReactNode is a React type for content that React can render.
- Now use it on App.jsx:
```tsx
import Card from "./Card.tsx";

function App(){
    return(
        <div>
            <Card>
            <h1>Hello!</h1>
            <p>Welcome.</p>
            </Card>
        </div>
    )
}
```
- what ever inside content/element in Card element that is all are childrens to card.
- children is to make a component resusable while allowing the content inside it to change.

**Another Example**
- **Without children**
```tsx
function Box(){
    return <div>Hello</div>;
};
```
- Now every Box always says "Hello".

**With children**
```tsx
function Box({children}: {children: React.ReactNode}){
    return <div>{children}</div>;
};
```
- Now we can resue it with different content.
```tsx
<Box>
    <h2>Welcomme</h2>
</Box>

<Box>
    <p>This is my Profile</p>
</Box>

<Box>
    <button>Click me</button>
</Box>
```

**Why ReactNode**
- children can be many kinds of renderable content.
- Which is a useful general type.

**Remember**
- Props are inputs to a component.
- children is the prop containing content placed inside the component.
