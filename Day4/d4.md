#### Props with Objects and Type Reuse

- We learned how to pass individual props, but we'll make props cleaner and reusable using a typescript type.

**Create UserProps**
```tsx
type UserProps = {
    name: string;
    age: number;
    city: string;
};

function User({name, age, city}: UserProps){
    return (
        <div>
        <h2>{name}</h2>
        <p>Age: {age}</p>
        <p>City: {city}</p>
        </div>
    );
}
```
**Pass the props**
```tsx
<user name="Tharun" age={23} city="Nandyal" />
```
- React creates the props object conceptually
```ts
{
    name: "tharun",
    age:23,
    city: "nandyal"
}
```
- this `{name, age, city}: UserProps` destructures that props object.

**Optional Props**
```tsx
type UserProps = {
    name: string;
    age: number;
    city?: string;
};
```
- Now city is optional
```tsx
<User name="tharun" age={23}>
```
