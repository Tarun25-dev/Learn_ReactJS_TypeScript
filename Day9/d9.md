#### useState - Managing Component Data

- Today we will start one of the important react concept `state`.
- You already know normal variables:
```ts
let count = 0;
```
- But changing a normal variable doesn't make react update the ui.
- For data that changes while the component is running, react provides state.
```tsx
import {useState} from "react";
function App(){
    const [count, setCount] = useState(0);
    return(
        <div>
        <p>Count: {count}</p>
        <button onClick={() => setCount(count + 1)}>Increase</button>
        </div>
    );
}
export default App;

```
- count is a special variable it holds the current data.
- setCount is a react function that intenally creates function implementation and that return value asssigned to the count.
- When that event happens then it calls the function and update the UI component.
- Typescript automatically knows the type as count = number and setCount = accepts number
- But we do setCount("hello") ts throws an error.

**State with strings**
```tsx
import {useState} from "react";
function App(){
    const [name, setName] = useState("Tharun");
    return(
        <div>
        <h2>Hello {name}</h2>
        <button onClick={() =>setName("Rahul")}>Change Name</button>
        </div>
    );
}
```

**Explicit state type**
- Sometimes typescript can't infer the complete type.
- For example:
```tsx
type User = {
    name: string;
    age: number;
};

const [user, setUser] = useState<User>({
    name: "Tharun",
    age: 23,
});

setUser({
    name: "kumar",
    age: 22,

});
```
- What if we write setUser({name: "rahul"}); Error beacuse age is required.
- state updates are not ordinary variable assignments.
- We are not directly changing the count.
- We are requesting react to update the state.

**Practice**

```tsx
import {useState} from "react";

function App(){
    const [count, setCount] = useState(0);
    return (
        <div>
            <h3>Count: {count}</h3>
            <button onClick = {() => setCount(count+1)}>Increase</button>
            <button onClick = {() => setCount(count-1)}>Increase</button>
        </div>
    );
}
```
