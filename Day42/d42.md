#### useDeferredValue
- We already learned about useTransition which lets you mark a state update as non-urgent.
- Key difference:
- useTransition - delay a state update.
- useDeferredValue - Allow a value to lag behind.

**The problem:**

- Imagine a search with large list:
```text
search: laptop

laptop 1
laptop 2
laptop 3
...
laptop 10000
```
- We want input itself to update immediately, but the large result list doesn't necessarily need to update at exactly the same moment.
- We can keep:
```tsx
const [search, setSearch] = useState("");
```
- as the immediate value.
- Then create a deferred version:
```tsx
const deferredSearch = useDeferredValue(search);
```
- search -> updates immediately
- deferredSearch -> can update slightly later.

**Basic example:**
```tsx
function App(){
    const [search, setSearch] = useState("");
    const deferredSearch = useDeferredValue(search);
    return(
        <>
            <input value={search} onChange={event => setSearch(event.target.value)} />
            <p>Current: {search}</p>
            <p>Deferred: {deferredSearch}</p>
        </>
    );
}
```

- Why we have two value?
- suppose user types:
- l
- la
- lap
- lapt
- lapto
- laptop
- for every input of letter will be immediately update on search.
- and we used that search for fetch details from list so for every input it runs updates immediately, so for each letter it will be filter all the list from top to bottom.
- so for performance optimisation which is unnecessary to check thats why we use DefferedSeach.
- That can temperarily remain behind while react handles more expensive rendering.

- useTransition - control the state update by marking as non-urgent.
- useDeferredValue - this value can be allowed to lag behind.

**Real Example:**
```tsx
const products = Array.from({length:1000}, (_,index) => `Product ${index+1}`);
function App(){
    const [search, setSearch] = useState("");
    const [filteredProducts, setFilteredProducts] = useState(products);

    const [isPending, startTransition] = useTransition();
    function handleSearch(event: ChangeEvent<HTMLInputElement>){
        const value = event.target.value;

        setSearch(value);

        startTransition(() => {
            const filtered = products.filter((product) => {
                return product.toLowerCase().includes(value.toLowerCase());
            });
            setFilteredProducts(filtered);
        });
    }
    return(
        <>
        <input value={search} onChange={handleSearch} placeholder="Search Products">
        {isPending && (<p>Updating results...</p>)}
        <div>
            {filteredProducts.map((product) => (<p key={product}>{product}</p>))}
        </div>
        </>
    );
}
```
