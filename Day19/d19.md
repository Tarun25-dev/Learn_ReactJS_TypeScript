#### Lifting state Up

**The problem**
- Suppose two child components need to work with same piece of data.
- Instead of keeping seperate states in both children, We move the state to their closest common parent.
- Thas called  lifting state up.
**Example**
- Imagine: CounterDisplay component and CounterButtons component and both components need access to the same count.
- So instead of typing same state for two times we place that at their parent component.
- Parent Owns the state

```tsx
function App(){
    const [count, setCount] = useState(0);
    return(
        <div>
          <CounterDisplay count={count}>
          <CounterButtons onIncrease = {() => {setCount(prev => prev+1)}} onDecrease = {() => {setCount(prev => prev - 1)}}>
        </div>
    );
}
```
- Display component
```tsx
type Count = {
    count: number
}
function CounterDisplay({count}: Count){
    return(
        <h1>Count: {count}</h1>
    );
}
```

- Buttons component
```tsx
type CounterButtonsProps = {
    onIncrease: () => void;
    onDecrease: () => void;
}
function CounterButtons({onIncrease,onDecrease}: CounterButtonsProps){
    return(
        <div>
            <button onClick={onIncrease}>IncreaseCount</button>
            <button onClick={onDecrease}>DecreaseCount</button>
        </div>
    );
}
```

- Add reset functionality

```tsx
function App(){
    const [count, setCount] = useState(0);
    return(
        <div>
          <CounterDisplay count={count}>
          <CounterButtons onIncrease = {() => {setCount(prev => prev+1)}} onDecrease = {() => {setCount(prev => prev - 1)}} onReset={() => {setCount(0)}}>
        </div>
    );
}

type Count = {
    count: number
}
function CounterDisplay({count}: Count){
    return(
        <h1>Count: {count}</h1>
    );
}

type CounterButtonsProps = {
    onIncrease: () => void;
    onDecrease: () => void;
    onReset:() => void;
}
function CounterButtons({onIncrease,onDecrease}: CounterButtonsProps){
    return(
        <div>
            <button onClick={onIncrease}>IncreaseCount</button>
            <button onClick={onDecrease}>DecreaseCount</button>
            <button onClick={onReset}>ResetCount</button>
        </div>
    );
}
```
