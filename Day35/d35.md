#### useCallback - Keeping Fuction Reference stable

- Yesterday we created `useFetch(getUsers);`
- Problem: A function created inside inside a component gets a new reference on every render.
- But now We'll understanf why that matters and how useCallback solves it.

**Functions are recreated on every render**
- Consider:
```tsx
function App(){
    const [count, setCount] = useState(0);
    const sayhello = () => {
        console.log("Hello");
    };
    return(
        <button onClick={() => setCount(count+1)}></button>
    );
}
```
- Everytime count changes, App renders again and updates UI.
- But every time it renders the function sayhello() have different refernces beacuse react assusumes that after every render any  function inside that is as look as new function and give new reference.

**Why cause this problem**
- we created  useFetch hook and insdie useFectch:
- useEffect(() => {}, [fetchFunction]);
- we pass a function that automatically calls when fetchFunction changes.
- React compares dependencies by reference.

- **So we know that every time state changes then that sayhello() function runs and created new reference every time by react.
- **React thinks the dependency changed and useEffect runs again beacuse of the new reference.**

- sayHello() - reference-A renders and calls useEffect
- in sayHello() component add one element.
- So react re-renders and that element shows.
- As well as react knows that sayHello() is a new function and that also re-renders.
- after that sayHello() - Refernce-B it changes the refernece.
- So beacuse of that unwantedly that fetchFunction called even we dont change the state of the sayHello().

**useCallback**
- useCallback allows react to keep the same function reference between renders until its dependencies change.
```tsx
const sayHello = useCallback(() =>{
    console.log("Hello")
}, []);
```
- Like render1 -> function A, render2 -> function A, render3 -> function A,..
- The reference been constant as long as the dependenct array remains unchanged.
- Prevents unnecessary effect executions in certain designs.

- **useCallback**: remembers a function.
- **useMemo**: remembers a calculated value.
