#### Forms - Controlled Inputs

- We will connect state + input events to build a proper react form.
- This concept is everywhere in react applications.

- We can make the input value come from state:
```tsx
function App(){
    const [name, setName] = useState("");
    return(
        <div>
            <input value={name} onChange={event => setName(event.target.value)} />
            <p>Hello {name}</p>
        </div>
    );
}
```
- The value attribute in html defines the current value/content of the input field.
- So initial state is name = "" empty string and when state changes then value will be changed to the event.target.value.
- state -> value(name) -> input, input changes(event occurs) -> state changes -> react renders again.
- This is called a controlled input.

**Typescript event typing**
- Typescript can automatically infer the event type.
- If we create a seperate handler explicitly type it:
```tsx
import {useState} from "react";
import {ChangeEvent} from "react";

function App(){
    const [name. setName] = useState(""); //ts know name is a string

    function HandleChangeEvent(event: ChangeEvent<HTMLInputElement>){
        setName(event.target.value);
    }
    return(
        <div>
        <p>Name: {name}</p>
        <input value={name} onChange={HandleChangeEvent}/>
        </div>
    );
}
```

**Multiple Form Fields**
- Suppose we need name and Email:
```tsx
const [name, setName] = useState("");
const [email, setEmail] = useState("");

<input value={name} onChange = {event => setName(event.target.value)}/>
<input value={email} onChange = {event => setEmail(event.target.value)}/>

```
- Thats perfectly valid.

**Object state for a Form**
- When a form has many fields then an object can be useful:
```tsx
type FormData = {
    name: string;
    email: string;
}

const [form, setForm] = useState<FormData>({
    name:"", //initial value
    email:"",
});

```
- To update its previous name:
```tsx
setForm(prev => ({...prev,name:event.target.value}));
setForm(prev => ({...prev,email:event.target.value}));

```
- If an array of objects is there means there each object  contain one name property so that time we set ternary condition like this:
```tsx
setFrom(prev => prev.map(obj => obj.name === "Tharun" ? {...obj,name:event.target.value} : obj ));

```

- Now let me introduce the <form> event.
```tsx

    console.log("Form submitted");

```
- preventDefault() is an event method that stops the browser's default action for an event.
- If we don't use that method then browser does its default action when submit that is reload the total application.
- Then only we perform something on that event like we are saying form submitted after the event happends.
- and if we want to clear those value after the submit and comes to its normal starting state:
```tsx
function handleSubmit(event: FormEvent<HTMLFormElement>){
    event.preventDefault();
    console.log("Form submitted");
    setName("");
    setEmail("");
}
```

**Example:**
```tsx
type User={
    name: string;
    age: number;
};

function App(){
    const [users, setUsers] = useState<User[]>([]); // Empty array.
    const [name, setName] = useState("");
    const [age, setAge] = useState("");

    function handleName(event:ChangeEvent<HTMLInputElement>){
            setName(event.target.value);
    } 
    function handleAge(event:ChangeEvent<HTMLInputElement>){
            setAge(event.target.value);
    }

    function handleSubmit(event:SubmitEvent<HTMLFormElement>){
        event.preventDefault();
        console.log("Form submitted");

        const newUser = {
            name: name,
            age: age
        };
        setUsers(prev => [...prev,newUser]);

        setName("");
        setAge("");
    }
    return(
        <div>
            <form onSubmit={handleSubmit}>
                <input value={name} onChange={handleName} />
                <input value={age} onChange={handleAge} />
                <button type="submit">Submit</button>
            </form>
        </div>
    );
}
```
