#### Conditional Rendering

**Using the ternary operator**

```tsx
function App(){
    const isLoggedIn = true;

    return(
        <>
        {isLoggedIn ? <h1> Welcome </h1> : <h1>Please Login.</h1>}
        </>
    );
}
export default App;
```
- Why {} beacuse jsx expressions must be inside curly brackets.
- The ternary expression decides which content should be render.

**&& conditional rendering**
- Some times you only want to show something when a condition is true.
- just like single if statement only.
```tsx
function App(){
    const isAdmin = true;

    return(
        <>
        <h1>Dashboard</h1>
        {isAdmin && <button>Admin Settings</button>}
        </>
    );
}
export default App;
```
- This becomes more useful when the condition comes from props.
```tsx
type UserProps = {
    isAdmin: boolean;
}

function User({isAdmin}: UserProps){
    return(
        <div>
        <h2> User Profile </h2>
        {isAdmin && <p>Admin access</p>}
        </div>
    );
}

```
- When we use that component User:
```tsx
<User isAdmin={true}/>
```
- Typescript ensures isAdmin must be a boolean.

**Multiple Conditions**
```tsx
type UserProps = {
    isLoggedIn: boolean;
    isAdmin: boolean;
};

function User({isLoggedIn, isAdmin}: UserProps){
    return(
        <div>
            {!isLoggedIn ? (<p>Please login</p>): isAdmin ? (<p>Welcome Admin</p>): (<p>Welcome user</p>)}
        </div>
    );
}
```
- we'll constantly see and use: when you nedd either A or B, when you need A or nothing.

**practice**

```tsx
type User = {
    isLoggedIn: boolean;
    isAdmin: boolean;
};

function App({isLoggedIn, isAdmin}: User){
    return(
        <>
        {!isLoggedIn ? (<p>Please Login</p>): (<p>Welcome Back</p>)}
        {isAdmin && <p>Admin panel</p>}
        </>
    );
}
```
