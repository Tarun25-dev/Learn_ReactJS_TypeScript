#### useMemo - Memorizing expensive calculations

- How react can remember a calculated value and avoid recalculating it when its dependencies haven't changed.

```tsx
import {useMemo, useState} from "react";

function App(){
    const [count, setCount] = useState(0);

    const result = useMemo(() => {
        console.log("Calculating...");
        return count * 10;
    }, [count]);
    return(
        <div>
            <p>Count: {count}</p>
            <p>Result: {result}</p>
            <button onClick={() => setCount(prev => prev+1)}>Increase</button>
        </div>
    );
}

```
- useMemo = To avoid recalculating an expensive value one every render when its dependencies haven't changed.
- Used for **Performance optimization.**
- Two stages in useMemo hook:
- [1.] If dependencies changes then useMemo sees category changed and calculation/filter runs again and produce new result/derived data.
- [2.] If dependencies not changed then react remembers that result of calculation/filter and when we call that component again then it gives use the previous result only, beacuse even when we calculate same previous result as new result beacuse of nothing changed.

**Important distinction: useMemo VS useState**
- useState can stores data that can change.
- useMemo remembers a calculated value.
