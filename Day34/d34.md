#### Building a Reusable useFetch Custom Hook

- We learned to create a seperate function for api logic and now move the repeated loading/error/data logic into a custom hook.
- Now Imagine we already write the code for users with their name and email and also we given that loading,error and fetch pattern for that api logic.
- But imagine we also need products , posts , orders , or comments ,etc so generally we write repeated code just like users with same pattern like loading, error, fetch.
- That's where a custom hook helps: useFetch()
```tsx
function useFetch<T>(fetchFunction: ()=> Promise<T>){
    const [data, setData] = useState<T | null>(null);
    const [loading, setLoading] = useState<boolean>(true);
    const [error, setError] = useState<string | null>(null);

    useEffect(() => {
        async function loadData(){
            try{
                setLoading(true);
                setError(null);

                const result = await fetchFunction();
                setData(result);
            }
            catch{
                setError("Something went wrong");
            }
            finally{
                setLoading(flase);
            }
        }
        loadData();
    }, [fetchFunction]);
    return{
        data,
        loading,
        error,
    }
}
```
- T is a generic type which handles any type of data.
- so data initial value is null and when we useing this useFetch that time we need to tell which type of data it is: either object or array or tuple or a string or number or boolean.
 
**Pass the API function to the hook**
```tsx
async function getUsers(): Promise<User[]>([]){
    const response = await fetch("https://jsonplaceholder.typicode.com/users");

    if(!response.ok){
        throw new Error("Failed to Fetch Users");
    }

    return response.json();
}

```
- Now we will use that data and update the Ui:
```tsx
function App(){
    const {data: users, loading, error} = useFetch(getUsers); // destructuring

    if (loading){
        return <p>Loading users...</p>;
    }
    if (error){
        return <p>{error}</p>;
    }
    return(
        <div>
            <h1>Users</h1>
            {users.map((m) => <div key={m.id}><p>Name: {m.name}}</p><p></p>Email: {m.email}</div>)};
        </div>
    );
}
```
- data: users, typescript knows that data is an array from the fetchfunction like <User[]>([]);
- users is a rename of data, we changed that  according to the API what data will fecth from api if that is products then we name  it like data: products.
