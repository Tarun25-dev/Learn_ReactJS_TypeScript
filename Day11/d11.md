#### State with Objects

- Stroing a users profile:
```tsx
type User = {
    name:string;
    age: number;
};

function App(){
    const [user, setUser] = useState<User>({
        name: "Tharun",
        age: 23
    });
    return(
        <div>
        <h2>{user.name}</h2>
        <p>{user.age}</p>
        </div>
    );
}
export default App;
```
- The state is a User object.
- Ts knows: user.name is a string and user.age is a number.

**Updating one property**
- like setUser({name: "tharun"});
- Thats wrong beacuse new object must satisfy the User properties.
- Here age is missing.

**Spread the previous object**

```tsx
setUser(prev => ({
    ...prev,
    name: "Rahul",
}));
```
- Here we are creating a new object by updating the current existing state object.
- And we know that spread operator updates a property and rewrites it the older object properties and returns in new object.

**Don't mutate state**
- like user.name = "rahul";
- react should not be directly mutated.
- use like: setUser(prev => ({...prev,name:"rahul"}));

**Task**
```tsx
type Product = {
    name: string;
    price: number;
}

function App(){
    const [state, setState] = useState<Product>({name: "laptop", price: 50000});
    function ChangeName(){
        setState(prev => ({...prev,name: "mobile"}))
    }
    function ChangePrice(){
        setState(prev => ({...prev,price:prev.price + 1000}));
    }
    return(
        <div>
            <button onClick = {ChangeName}>Change Name</button>
            <button onClick = {ChangePrice}>Increase Price</button>
        </div>
    );
}
```
