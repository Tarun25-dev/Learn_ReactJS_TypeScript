#### useTransition

- We'll learn useTransition for marking some state update as non-urgent.
- The main idea:
```text
Urgent update -> Immediately happens
Transition update -> react keep the UI responsive while processing it.
```
- This is especially useful when an interaction triggers expensive rendering, such as filtering a large list.

**Basic synatx**
```tsx
const [isPending, startTransition] = useTransition();
```
- isPending is a boolean and true when the transition is still being processed.
- startTransition is function used to mark a state update as non-urgent:
```tsx
startTransition(() => {
    setState();
});
```

**Symple Example:**
```tsx
function App(){
    const [count, setCount] = useState(0);
    const [isPending, startTransition] = useTransition();

    function handleClick(){
        startTransition(() => {
            setCount(prev => prev + 1);
        });
    }
    return(
        <>
        <p>Count: {count}</p>
        <button onClick={handleClick} >Increase</button>
        {isPending && (<p>Updating</p>)}
        </>
    );
}
```
**Why do we need this?**
- Imagine a search box containing 10,000 products.
- We need to find out one product category and react needs to filter and render thousands of products.If the update is expensive the UI might fell less responsive.
- We can mark the expensive update as a transition, Then react knows this update is less urgent than keeping the interface responsive.

**Real Example**
```tsx
const products = Array.from({length:10000}, (_,index) => `Product ${index+1}`);

function App(){
    const [search, setSearch] = useState("");

    function handleSearch(event: React.ChangeEvent<HTMLInputElement>){
        const value = event.target.value;

        // urgent update
        setSearch(value);

        // transition non-urgent
        startTransition(() => {
            const filtered = products.filter((product) => 
            // first i need to convert that all products names into lowercase throught iteration
            product
                .toLowerCase()
                .includes(value.toLowerCase) //user typed value takes as lowercase and checking wheter that word is in the product or not.
            );
        });
        return(
            <>
            <input value={search} onChange={handleSearch} placeholder="Search Products">
            {isPending && (<p>Updating results...</p>)}
            <div>
                {filteredProducts.map((product) => (<p key={product}>{product}</p>))}
            </div>
            </>
        );
    }

}
```
