#### React.memo - Preventing Unnecessary child Re-renders

- We already know about:
- useMemo -> memorizes a value
- useCallback -> memorizes a function
- Now use React.memo which works at the component level.
- React.memo is a react API/function provided by the react lib.

**The idea**
- Suppose App has a counter and a child component:
```text
App
 |______Counter(child)
 |
 |______UserProfile(child)
 |
```
- When the counter changes App re-renders.
- Normally UserProfile also renders again even if its props haven't changed.
- React.memo can prevent that unncessary child render.

**Use React.memo**
```tsx
import {memo, useState} from "react";

type UserProps = {
    name: string;
};

const UserProfile = memo(function UserProfile({name}: UserProps){
    console.log("User Profile rendered");
    return <h1>Hello {name}</h1>
});
```
- Now React compares the components props.
- If name = "Tharun", hasn't changed then react can reuse the previous rendered result.
- So count chnages -> App renders -> UserProfile props unchanged -> UserProfile doesn't need to render again.
- memo can skip re-redering a component when its props haven't changed.

```note
memo = memorizes a components rendering based on props.
useMemo = memorizes a calculated value.
useCallback = memorizes a function reference.
```
